# Checklist web

- [ ] Público, autenticado y no autorizado.
- [ ] Desktop, tablet y móvil.
- [ ] Loading, vacío, error, parcial y datos largos.
- [ ] Teclado, foco visible, lectores y contraste.
- [ ] Formularios con validación, doble envío y recuperación.
- [ ] Tablas con filtros, paginación y acciones consistentes.
- [ ] SSR/SEO solo para contenido público.
- [ ] Sin IDs/rutas/proveedores internos en UI.
- [ ] Cookies, CORS, CSP y caché correctos.
- [ ] Playwright cubre flujos críticos.
