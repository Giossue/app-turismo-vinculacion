# Control de versiones

- Commits pequeños y coherentes.
- Formato recomendado: `type(scope): imperative subject`, máximo 72 caracteres.
- Tipos: `feat`, `fix`, `docs`, `test`, `refactor`, `perf`, `build`, `ci`, `chore`.
- No mezclar migración, refactor amplio y feature no relacionada.
- No reescribir historia publicada sin autorización.
- No hacer commit/push desde un agente salvo solicitud explícita.
- Revisar lockfiles; no actualizar todas las dependencias accidentalmente.
- Código generado y migraciones se confirman con su fuente.
