# Checklist móvil

- [ ] Android/iOS y tamaños soportados.
- [ ] Permisos: no solicitado, denegado, permanente, GPS apagado.
- [ ] Ubicación desactivada conserva exploración y origen manual.
- [ ] Foreground/background se inicia y detiene correctamente.
- [ ] Deep links, back, cold start y restauración.
- [ ] Offline, red lenta, timeout y reintento.
- [ ] Texto grande, lector de pantalla, contraste y touch targets.
- [ ] Teclado, formularios largos y pérdida de borrador.
- [ ] Imágenes/video/audio con progreso, cancelación y error.
- [ ] Tokens seguros y logout completo.
- [ ] Sin claves privilegiadas en el binario.
