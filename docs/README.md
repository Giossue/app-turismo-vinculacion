# Índice de documentación

- `product/`: propósito, usuarios, dominio, glosario y funcionalidades.
- `architecture/`: stack, límites, mapas, IA, datos y despliegue.
- `plans/`: trabajos activos, completados y deuda técnica.
- `quality/`: pruebas, revisión, rendimiento, observabilidad y Definition of Done.
- `security/`: principios, amenazas, hardening y privacidad de ubicación.
- `generated/`: referencias generadas; no editar manualmente.

Cuando cambie el comportamiento, actualizar la especificación y arquitectura afectadas
en la misma unidad de trabajo.
