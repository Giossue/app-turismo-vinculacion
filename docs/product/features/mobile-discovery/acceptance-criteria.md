# Criterios de aceptación

- [ ] La aplicación se analiza y prueba con TypeScript local.
- [ ] El listado solo representa el contrato público de la API.
- [ ] Carga, vacío, error y reintento son distinguibles y accesibles.
- [ ] No se solicita ubicación ni se persiste información personal.
- [ ] MapLibre recibe exclusivamente marcadores publicados desde la API.
- [ ] La navegación continúa fuera de alcance y no solicita ubicación.
