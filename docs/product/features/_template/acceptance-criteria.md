# Criterios de aceptación

- [ ] Camino feliz observable.
- [ ] Autorización por rol y registro.
- [ ] Validaciones y errores de negocio.
- [ ] Loading, vacío, error, offline y reintento.
- [ ] Accesibilidad y tamaños soportados.
- [ ] Auditoría/telemetría cuando aplique.
- [ ] Pruebas unitarias, integración y E2E apropiadas.
- [ ] Documentación y OpenAPI actualizados.
